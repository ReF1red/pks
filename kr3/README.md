# Практическое занятие №3 — Программирование корпоративных систем

WPF-приложение для мониторинга HTTP-запросов:

- `HttpListener` сервер (GET/POST);
- `HttpClient` клиент для внешних API и локального сервера;
- логирование входящих/исходящих запросов в интерфейс и в файл `logs.txt`;
- фильтрация логов по методу и статусу;
- аналитика: счётчики, среднее время обработки, **график пиковой нагрузки** запросов
  в разрезе минутного/часового мониторинга (столбчатая диаграмма с осями + таблица).

## Структура

- `HttpMonitorApp/HttpMonitorApp.csproj` — проект WPF;
- `HttpMonitorApp/MainWindow.xaml` — интерфейс;
- `HttpMonitorApp/MainWindow.xaml.cs` — логика сервера, клиента и мониторинга.

## Запуск

1. Открыть проект `HttpMonitorApp` в Visual Studio на Windows(или в эмуляторе windows НЕ ЗАБЫТЬ).
2. Собрать и запустить.
3. На вкладке **Сервер** задать порт и нажать **Запустить сервер**.
4. На вкладке **Клиент** отправлять GET/POST запросы.
5. На вкладке **Логи и фильтры** смотреть и фильтровать записи.
